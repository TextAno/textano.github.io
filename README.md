# TextAno – personenbezogene Angaben ersetzen, bevor Texte in die KI gehen

**TextAno** ersetzt Namen, Adressen, Telefonnummern, AHV-Nummern, IBAN und weitere personenbezogene Angaben in einem Text durch Platzhalter wie `[PERSON_1]`, bevor Sie den Text in ein KI-Tool wie ChatGPT, Claude oder Duck.ai geben. Die Antwort der KI setzt TextAno danach wieder zurück: Die Platzhalter werden durch die Originalwerte ersetzt.

Webseite mit Demo: **https://textano.github.io/**

## Das Wichtigste in Kürze

- **Lokal im Browser:** TextAno ist eine einzelne HTML-Datei. Die Verarbeitung läuft im Browser; die Datei sperrt Netzwerkverbindungen (einzige Ausnahme: die Update-Prüfung nach Bestätigung, ohne Übertragung von Texten).
- **Keine Installation:** Datei herunterladen und in einem aktuellen Browser öffnen. Kein Konto, kein Server.
- **Pseudonymisierung, keine Anonymisierung:** TextAno behält die Zuordnung Platzhalter → Originalwert, damit die Antwort der KI zurückübersetzt werden kann. Im Sinne des Datenschutzrechts ist das eine Pseudonymisierung.
- **Kontrolle beim Menschen:** Jede Ersetzung ist sichtbar und änderbar. Die Erkennung findet nicht jede Angabe – prüfen Sie das Ergebnis vor jeder Weitergabe.
- **Vier Sprachen:** Deutsch, Französisch, Italienisch, Englisch; Schweizer Angaben (AHV-Nummer, UID, Kontrollschild, Postleitzahl) werden erkannt.
- **Preise:** Einfachmodus für private Zwecke gratis; für geschäftliche Nutzung und den Expertenmodus gibt es Monats- und Jahreslizenzen (Preise auf der Webseite).

TextAno ist ein Hilfsmittel. Es ersetzt keine eigene Prüfung und keine rechtliche Beratung. Für die Nutzung gelten die Endbenutzer-Lizenzvereinbarung (EULA) und der Wichtige Hinweis, die das Tool beim ersten Start anzeigt.
